T7Difficulty - BUILD / INSTALL / FIRST TEST
===========================================

WHAT THIS VERSION DOES
----------------------
- Same project architecture as SC6Difficulty:
  * XINPUT1_3 transparent proxy loader
  * SafetyHook backend hooks
  * D3D11 overlay only while Options is open
  * L1/R1 (LB/RB) and Z/X selector
  * INI load on startup
  * INI save on every Options exit

- TEKKEN 7 selector:
  0 = Default       (NO intervention; vanilla Treasure scaling)
  1 = Easy          base=0 profile=0
  2 = Medium        base=1 profile=5
  3 = Hard          base=2 profile=10
  4 = Very Hard     base=3 profile=17
  5 = Ultra Hard    base=4 profile=19

- Treasure gate:
  exe+2600BA, EAX == 0x0B

- Final AI resolver:
  exe+70D009, overrides R14D/R9D only when:
    Treasure == true AND selected difficulty != Default

- Options detection:
  language-independent live Scaleform owner signature using
  mc.List1_Panel_mc.Panel6.OptionName_mc.DT_OptionName_mc
  plus structural validation.

BUILD REQUIREMENTS
------------------
Visual Studio 2022 with:
- Desktop development with C++
- MSVC v143
- Windows 10/11 SDK

FIRST BUILD (recommended)
-------------------------
1. Open T7Difficulty.sln.
2. Select:
      Debug
      x64
   Do NOT build Win32/x86.
3. Build -> Build Solution.
4. Output directory is normally:
      x64\Debug\
5. The build produces:
      XINPUT1_3.dll       <- drop-in proxy version
      T7Difficulty.dll    <- identical binary, convenient manual-injection alias

INSTALL AS XINPUT PROXY
-----------------------
1. Find the folder containing:
      TekkenGame-Win64-Shipping.exe

   Normally this is:
      ...\TEKKEN 7\TekkenGame\Binaries\Win64\

2. IMPORTANT: if that folder already contains XINPUT1_3.dll, back it up first.

3. Copy the built XINPUT1_3.dll into that same folder.

4. Start Tekken 7 normally.

5. In the same folder as the loaded mod DLL you should get:
      T7Difficulty.log

   If NO T7Difficulty.log appears at all, the proxy was not loaded.
   Do not debug the AI code in that case: it is only a loading/injection issue.

MANUAL-INJECTION FALLBACK
-------------------------
The post-build step also creates T7Difficulty.dll.
If your exact Tekken 7 build does not load the local XINPUT1_3 proxy, inject
T7Difficulty.dll into TekkenGame-Win64-Shipping.exe with a 64-bit DLL loader.
The mod logic is the same.

FIRST FUNCTIONAL TEST
---------------------
1. Start the game and inspect T7Difficulty.log.
   Expected core lines:
      T7Difficulty loaded
      Treasure mode hook installed.
      Final AI resolver hook installed.
      XInput initialized.
      Options detector initialized.
      Overlay hooks installed.
      Initialization finished.

2. Enter the main Options screen.
   The overlay should appear in the top-right corner.

3. Change the selector with:
      L1 / LB / Z = previous
      R1 / RB / X = next

   Values:
      DEFAULT
      EASY
      MEDIUM
      HARD
      VERY HARD
      ULTRA HARD

4. Exit Options.
   T7Difficulty.ini is written/updated automatically:

      [Difficulty]
      TreasureBattle=N

5. Re-enter Options and verify the selected value persisted.

6. Set ULTRA HARD, exit Options, enter Treasure Battle and play.
   The final resolver should use base=4/profile=19.

7. For detailed first-run diagnostics, keep Debug x64:
   the log additionally records mode transitions and final AI overrides.

8. Once everything is confirmed, rebuild:
      Release
      x64
   and replace the Debug DLL with x64\Release\XINPUT1_3.dll.

IMPORTANT VERSION CHECK
-----------------------
The mod validates the two proven hook instructions before installing hooks:
- exe+2600BA must begin with: 83 F8 05
- exe+70D009 must begin with: 49 63 C1

If your executable differs, T7Difficulty.log will report a signature mismatch
and the mod will stop instead of hooking a wrong address.

INI
---
The original difficulty key remains compatible:

  [Difficulty]
  TreasureBattle=0

0 means true vanilla/default behaviour: the final AI resolver is left alone.

TREASURE BATTLE EXTENSIONS (2021 NoDVD)
--------------------------------------
Three overlay rows: CPU Difficulty (same values and policy), Rounds, Special Battles.
L3 / TAB cycles the row. L1/R1 or Z/X changes its value (new presses only).
Input requires Options open and the game focused. All three settings save on Options exit.
Older INIs continue to load: missing new keys default to zero (Vanilla).
Rounds: Default, 1, 2, 3, 4, 5 wins required.
Special Battles overlay: Vanilla, No Turbo, No Double Damage, No Turbo & Double Damage, Disabled.
INI [TreasureBattle]: Rounds=0 and SpecialFights=0.
SpecialFights: 0 Vanilla; 1 suppress type 5; 2 suppress type 4;
3 suppress types 4/5; 4 Disabled suppresses types 1/2/4/5/6/7.
The specification duplicated value 2; Disabled is assigned 4 to keep every policy distinct.
Unknown encounter types are untouched. No character, rank or reward code is changed.

Additional hooks require x64 timestamp 616E792F and exact instruction contexts.
Verified executable SHA256:
e7d8443dcbd607c32be352777b216857ddd01c4d5f31217d58c50b1da7b3274f
SHA256 was checked offline; runtime validates timestamp and instruction bytes.
Entry 437A60: push rbx/rdi/r12/r15; sub rsp,28; context preserves RDX in R15.
Calls 437DDE and 438F49: argument setup EDX=2; CALL 2C90A0.
Setter 2C90A0: mov [rcx+A0],edx; ret. Setter is validated, never hooked.
Only these Treasure call sites are intercepted, additionally gated by Treasure mode.
Any validation/installation failure disables the extension group, preserving difficulty.
No EXE on disk is changed; no Steam or dinput8 dependency is added.
Debug logs hook installation, actual encounter changes and actual round overrides.

VERIFICATION / MANUAL TESTS STILL REQUIRED
------------------------------------------
Static policy checks: tests/TreasurePolicyTests.cpp, compile with MSVC /std:c++20 /c.
Checks cover Vanilla, each special filter, unknown types, Rounds 0-5 and row-value cycling.
Disassembly and executable identity checked against the local NoDVD; no Steam RVAs assumed.
In-game tests have NOT been run. Before considering runtime behavior verified:
- Compare every difficulty value with the original mod, including Default rank scaling.
- Check three rows at common resolutions, L3/TAB and L1/R1/Z/X, held buttons,
  simultaneous presses, loss of focus and inputs outside Options.
- Exit Options/restart; verify all settings, old INIs and invalid values.
- Rounds 0-5: test initial Treasure match and subsequent matches, wins/losses/continue.
- Vanilla: observe natural specials; No Turbo: only Turbo removed; Disabled: all
  identified specials removed, normal encounters unchanged. Exercise No Double Damage and No Turbo & Double Damage from the overlay.
- Verify characters, ranks and rewards behave normally across those encounters.
- Verify Arcade, Practice, Versus and online modes receive no new overrides.
- On an incompatible executable, confirm extensions report disabled and difficulty works
  whenever its original two instruction signatures still match.
- Test Debug logs and Release proxy startup independently. Do not load both DLL aliases.

LOCAL INSTALLATION
------------------
Build x64 Release and copy XINPUT1_3.dll beside TekkenGame-Win64-Shipping.exe.
T7Difficulty.dll is the identical manual-injection alias; load only one copy.
Preserve an existing T7Difficulty.ini (missing keys default to Vanilla).
Close Tekken 7 before replacing a loaded DLL. No GitHub release or merge is required.
